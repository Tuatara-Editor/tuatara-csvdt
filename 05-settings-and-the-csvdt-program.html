Settings and the csvdt program

The package's settings, and how to point it at a csvdt that is not on the PATH.

Each setting has its help in C-h v. Chapter 6 lists them with their defaults. Set them in the init file, after :config of load-package.

5.1 The csvdt program

*csvdt-program* is a name, looked for on the PATH, or a full path from / or ~. A full path is the file that is run, and it is never looked for on the PATH. A relative path such as "./target/release/csvdt" is refused, because it would run whatever file of that name stands beside the CSV file.

(load-package "csvdt" :source "https://github.com/Tuatara-Editor/tuatara-csvdt"
  :config
  (setf *csvdt-program* "~/src/csvdt/target/release/csvdt"))

5.2 The arguments

*csvdt-default-arguments* is the text the argument line starts with. The default, -H -p, suits a file with a header row, the header printed. Use "" for none.

5.3 Obsolete settings

Five settings fed the package's own reading of the buffer as CSV, which csvdt now does itself (chapter 2). They are obsolete: they do nothing, and are removed in the next major version. Setting one is harmless.

  • *csvdt-region-carries-header*: whether the buffer's header went in front of a selection. csvdt always takes the buffer's first record for the header now.
  • *csvdt-header-options*, *csvdt-single-quote-options*, *csvdt-read-delimiter-options* and *csvdt-comment-options*: the names of the options saying the first record is a header, making ' the quote character, setting the delimiter fields are read with, and naming a comment character. A run over part of a buffer under =--comment is no longer refused.

5.4 The output mode

*csvdt-output-mode* is the major mode of *csvdt output*. See chapter 4.

5.5 How much csvdt may write

*csvdt-output-multiple* is how much csvdt may write for a run, as a multiple of its input: 8 by default, and never less than 64 MB, nor more than a quarter of the editor's free memory. A run that writes more is ended. See chapter 4.

(load-package "csvdt" :source "https://github.com/Tuatara-Editor/tuatara-csvdt"
  :config
  (setf *csvdt-output-multiple* 32))

5.6 Tests

tools/test.sh in the package runs its tests. The runs of csvdt need a program to run: CSVDT=/path/to/csvdt names it, else the one on the PATH is used. Without one those tests are skipped, not passed.
