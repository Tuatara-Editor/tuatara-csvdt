What gets processed

Which lines go to csvdt, and how they are widened to whole records.

csvdt-run-dwim takes the banked lines and the selection together, merged so a line in both goes once. With neither, it takes the whole buffer.

Banked lines are Tuatara's own (bank-lines, m l in normal state). They go to csvdt as one file in buffer order, so a duration is measured across what was banked rather than across the lines between. Running over them leaves them banked.

The selection is taken as y and d take it: a line selection whole, a rectangle by the rows it spans. A rectangle's columns are ignored, because picking columns is csvdt's job (--remove, -a). A run takes the main selection only, not the places of several cursors or of a split.

csvdt-describe-run says what a run would cover, without running it. It has no line of arguments to read yet, so it reads them from *csvdt-default-arguments*. It works in the background too.

2.1 Whole records

Whatever was picked, whole records are what go out.

  • A selection that starts or ends inside a line takes the whole line. The run says , selection widened to whole lines.
  • A quoted field can hold a line end, so a record is not always a line. The range is pushed out to record boundaries, and the run says , widened to whole records: a quoted field spans lines. Finding the boundaries reads the buffer once, quote to quote, from its start to the last range, as part of the run in the background. A whole-buffer run reads nothing.
  • Two banked lines inside one multi-line record widen to the same record, and it is sent once.

2.2 The header

When the arguments ask for a header and what is sent starts below it, the buffer's header record goes in front. Then csvdt does not take the first selected row for the header. Set *csvdt-region-carries-header* to nil to stop this. csvdt then takes the first selected row for the header without saying so, and that row goes through unconverted.

2.3 What decides where a record begins

--single-quote and --read-delimiter are read from the arguments before any of the above, because they decide where a record begins. A quote only opens a field where a field begins, and that depends on the delimiter. The names of the options that do this are in settings, chapter 5.

2.4 The bytes

The buffer's bytes go to csvdt as they are. A file that is not UTF-8 reaches csvdt as it is on disk, and csvdt refuses it in its own words. Line ends are sent as \n when the buffer's are \r\n.
