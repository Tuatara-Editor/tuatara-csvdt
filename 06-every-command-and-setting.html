Every command and setting

Each command and setting of the csvdt package, to look one up by name.

The tables are made from the program each time this manual is made, so they never list a command or setting that the package does not have. The first table has four columns. The first two are keys: the modal keys, which work only with modal editing on, and the non-modal keys, which work with it off too. A command with no key says M-x and its name in the second column, because you can only run it by its name. The third column is the name of the command and the fourth says what it does.

To run a command by its name, press M-x, type a few letters of the name and press RET. To find a command from within the editor, press C-h f. To find the command that a key runs, press C-h k and then the key. The editor's own settings and commands are in chapters 21 and 22 of its manual.

6.1 Every command

ModalNon-modalCommandWhat it does
noneC-c v ?csvdt-describe-runSay what M-x csvdt-run-dwim would cover, and from what, without running anything: for when a run covered more or less than expected.
noneC-c v hcsvdt-helpShow csvdt's own –help, read from the program each time, so that it is always that of the csvdt that runs.
noneC-c v kcsvdt-run-bankedRun csvdt over the banked lines (C-z m l) with arguments read in the minibuffer: the output following the buffer's order.
noneC-c v bcsvdt-run-bufferRun csvdt over the whole buffer with arguments read in the minibuffer (M-x csvdt-run-dwim says how they are read); show what it writes in csvdt output.
noneC-c v rcsvdt-run-dwimRun csvdt over the banked lines and the selection together, or with neither over the whole buffer; show what it writes in csvdt output.
noneC-c v SPCcsvdt-run-regionRun csvdt over the lines of the selection with arguments read in the minibuffer: to try something on a few rows before the whole file.
noneC-c v vcsvdt-versionSay which csvdt runs, and which time zone database is built into it.
